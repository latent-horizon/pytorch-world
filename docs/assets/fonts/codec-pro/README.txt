# Codec Pro

Text font of the docs. Codec Pro is a commercial typeface by Zetafonts; add the
web-licensed files here:

| file | weight |
|---|---|
| `CodecPro-Regular.woff2` | 400 |
| `CodecPro-News.woff2` | 500 |
| `CodecPro-Bold.woff2` | 600 |
| `CodecPro-ExtraBold.woff2` | 700 |

The `@font-face` rules are at the top of `docs/stylesheets/sunset.css`. Until
the files are here, pages fall back to Inter.
